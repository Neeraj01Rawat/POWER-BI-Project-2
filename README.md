# 👥 HR Analytics Dashboard

## 📌 Overview

This project is a Power BI dashboard built to analyze employee attrition and workforce trends through interactive visualizations and key HR metrics. The dashboard provides insights into employee demographics, attrition patterns, and job-related factors.

## 🛠️ Tool Used

- Power BI

## 📊 Dashboard Highlights

- Total Employees
- Total Attrition
- Attrition Rate
- Average Age
- Average Salary
- Average Years at Company
- Attrition analysis by Education
- Attrition analysis by Age Group
- Attrition analysis by Salary Range
- Attrition analysis by Education Level
- Attrition analysis by Job Role
- Attrition analysis by Satisfaction Level
- Department-wise filtering (Human Resources, Research & Development, Sales)
- Gender-based overview
